# Setup Examples

These files are templates. Merge them with existing configuration rather than copying over unrelated settings.

- `vscode-settings.json` -> merge into workspace `.vscode/settings.json` if you want to make AGENTS.md behavior explicit.
- `vscode-mcp.json` -> merge into workspace `.vscode/mcp.json` to add the OpenAI developer documentation MCP server for VS Code/Copilot.
- `codex-config.toml` -> merge into `~/.codex/config.toml` to add the same documentation MCP server for Codex CLI/IDE.
